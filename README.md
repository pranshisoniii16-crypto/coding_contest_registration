#Coding Contest Registration System 

Project Description :
This is a simple Python mini project developed for a Coding Contest Registration System.

The program allows a student to:

Enter their name
Enter their college name
Select a coding contest event
Select a preferred time slot
View the registration details
View the registration fee
The registration details and fee are displayed at the end of the program.
